# 📜 Poetry App Backend

This is the backend for a **Poetry App** built using **Node.js**, **Express.js**, and **MongoDB**. It provides a RESTful API to handle poetry.

---

## ✨ Features

- ✍️ Create, read, update, delete poems
- 📁 Categorize poems by genre or tags
- 👤 Private and public poems
- 🌐 RESTful API with JSON responses

---

## 🧱 Tech Stack

- **Node.js** – Runtime environment
- **Express.js** – Web framework
- **MongoDB** – NoSQL database
- **Mongoose** – MongoDB object modeling
- **dotenv** – Environment variable management
- **CORS**,**Body-parser**, etc.
